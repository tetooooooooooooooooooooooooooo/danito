{{ head("Moderation log", "A separate record of the punishments handed out with Newt's own commands, each one numbered so you can look it up later.") }}

This is the one to use if you want a clean list of moderator actions. The server log above records everything that happens, however it happened; this records only what was done with /ban, /kick, /timeout, /warn and the rest, and gives each a case number. With both switched on, a ban placed with /ban is written here as a case rather than in both places.

{{ head("Deleted media", "Keeps the file itself when somebody deletes an image, video or voice memo, not just the filename.") }}

Separate from the server log above because it re-uploads the actual file. Deleted messages carrying a picture are reported here rather than in both.

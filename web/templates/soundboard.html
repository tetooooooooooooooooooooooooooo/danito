This re-uploads sounds

Reordering re-uploads sounds.

  • Each re-uploaded sound gets a new id, so Discord treats it as a different sound.
  • It disappears from every member's favourites on this server, and there is no way to put it back for them.
  • The audio, name, emoji and volume are all kept.
  • This cannot be undone.
